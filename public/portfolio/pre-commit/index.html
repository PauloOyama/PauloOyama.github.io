Pre-Commit Para Grupos de Trabalho

9 de agosto de 2024 · 1 min · Paulo Oyama |  Sugerir mudanças

O projeto#

Este projeto aborda como padronizar código Python em equipes usando pre-commit hooks com ferramentas como Black e Flake8, integrando a verificação automaticamente ao fluxo de versionamento via Git.

O projeto está dividido em:

  • Enforcement Style Guide — Por que e como padronizar código Python com linters.
  • Pre-Commit — Configurando o pre-commit para aplicar os linters automaticamente.
